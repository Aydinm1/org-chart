# Midwest Institutions Directory

Next.js org directory backed by Airtable.

## Environment Variables

Set these on the server:

- `AIRTABLE_API_KEY`
- `AIRTABLE_BASE_ID`

## Airtable Tables

The app expects these Airtable tables:

- `Groups`
- `People`
- `Display Sections`
- `Memberships`
- `Unit Placements`

## Development

```bash
npm run dev
```

## Production

```bash
npm run build
npm run start
```
